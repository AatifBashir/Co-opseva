# HOW TO RUN LOCALLY

## Prerequisites:

 - Node.js (v18 or higher recommended)

 - npm (comes with Node.js)

 - Git

## Step-by-Step Setup:

 - Clone the repository:
 - git clone https://github.com//CO-OPSEVA.git
 - cd CO-OPSEVA

## Install dependencies:
```
npm install
```

(If you encounter any peer dependency issues on other machines, use: npm install --legacy-peer-deps)

Start the development server:
```
npx expo start --web -c
```
Open the application:
Go to http://localhost:8081 in your browser.
